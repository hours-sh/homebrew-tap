# hours Homebrew tap

Homebrew formula for the [hours](https://hours.sh) command line interface.

`Formula/hours.rb` is generated by `cli-release.yaml` in
[248-sh/hours](https://github.com/248-sh/hours) on every release. Do not edit
this repository by hand.

## Install

```sh
brew install hours-sh/tap/hours
hours --version
```
